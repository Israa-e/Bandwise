# Speaking examiner audio

Original practice questions written for Bandwise; they are not IELTS questions. Every line the examiner says has a stable id in `content.json` and its own recording, `mp3/<id>.mp3`.

> Generated by `dart run tool/build_speaking_audio.dart --readme`. Edit content.json, then regenerate; do not edit this file by hand.

## Engine and licences

| | |
| --- | --- |
| Speech | Kokoro-82M (hexgrad), the `kokoro-en-v0_19` package run locally with sherpa-onnx |
| Licence | Apache-2.0 (Kokoro-82M weights; sherpa-onnx). Commercial use is allowed. |
| Voice | Built-in British male voice `bm_george`, speed 0.95. No voice is cloned. |
| Checking | Every take is transcribed with faster-whisper `Systran/faster-whisper-large-v3` (MIT) and must contain the script's words. It is only used to check takes; nothing from it is shipped. |
| Runtime | The Python environment bundled with VoiceStudio 0.5.6, called directly (not through its API), as for Listening |

VoiceStudio's default engine (OmniVoice) was not used: its model is licensed CC-BY-NC (non-commercial). See ../listening/README.md.

## Rebuilding

```sh
# 1. audio/<id>.wav for every line (resume-safe; --redo id,id to regenerate)
~/.config/VoiceStudio/runtime/project/.venv/bin/python tool/generate_speaking_voices.py
# 2. mp3/<id>.mp3 (needs ffmpeg)
dart run tool/build_speaking_audio.dart
```

The `audio/` folder is not committed; `mp3/` is. Recordings made by learners are never stored here: they stay on their device.
