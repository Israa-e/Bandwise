## Build

Needs ffmpeg with libmp3lame.

```sh
dart run tool/build_listening_audio.dart set_a
```

This writes `listening.mp3` (mono, 64 kbps, loudness-normalised) and `timestamps.json` (start/end ms of every line) to this folder.
